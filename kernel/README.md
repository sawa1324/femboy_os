# Femboy OS Kernel

Минимальное ядро для операционной системы **Femboy OS**.

## 📁 Структура

```
kernel/
├── arch/x86_64/src/           # Исходный код для x86-64
│   └── entry.asm              # Entry point (assembly)
├── main.c                     # Основная точка входа на C
└── README.md                  # Эта файл
```

## 🛠️ Сборка

### Предварительные требования:
1. **Limine** должен быть установлен и скомпилирован (находится в `../limine/`)
2. **GCC 6.3+** или совместимый компилятор (или Clang)
3. **QEMU** для тестирования

### Команды сборки:

```bash
# Сборка только ядра (для отладки)
make boot

# Сборка и запуск в QEMU
make run
```

## 🚀 Запуск в QEMU

После выполнения `make run` запустится QEMU с образом диска, содержащим:
- Загрузчик **Limine**
- Ядро **Femboy OS v0.1.0**

Ожидаемый вывод при успешной загрузке:
```
Femboy OS v0.1.0 - Booted!
Initializing kernel...
```

## 📝 Архитектура

- **Архитектура:** x86-64 (Intel/AMD)
- **Ядро:** Собственное, модульное монолитное
- **Загрузчик:** Limine v6+
- **Разработка:** Windows + Ubuntu через WSL
- **Тестирование:** QEMU → реальное железо

## 🎨 Темы

1. **Пастельная** (по умолчанию) - нежные, светлые тона
2. **Кибер** (альтернатива) - тёмная тема с неоновыми акцентами

Темы будут загружаться автоматически при инициализации ядра.
