# femboy_os
Femboy OS — an open-source operating system with its own kernel.
Основные решения
Архитектура: x86-64, Intel/AMD.
Ядро: собственное, модульное монолитное.
Языки ядра: C и x86-64 Assembly.
Загрузчик: Limine.
Разработка: Windows + Ubuntu через WSL.
Тестирование: QEMU, затем реальное железо.
Сборка: Make и freestanding toolchain.
Сначала одно процессорное ядро, позже SMP.
Сначала framebuffer и 2D, позже GPU и 3D.
Пастельная тема по умолчанию; тёмная кибер-тема как альтернатива.
В будущем: GUI, файловый менеджер, терминал, сеть, звук, игры, SDK, пакетный менеджер и совместимость с Linux-программами.
Каналы обновлений: Stable и Experimental.
Установка системных обновлений должна подтверждаться пользователем.
Репозиторий пока приватный, открытие проекта планируется позднее.
